# ORBIT - Agentic-Engineering-Methodology

ORBIT is an evolving methodology for human-AI collaboration.

The purpose of this repository is not to implement a software framework,
but to investigate, define, document and evolve the foundations of
agentic collaboration.

ORBIT is intentionally tool-agnostic.

The methodology itself is developed through Orbit Evolution Proposals (OEPs).

## Current Status

ORBIT is in its foundational research phase.

No fundamental architecture has been finalized yet.

## Important

Do not treat existing documents as immutable truth.

Some concepts, principles and classifications are hypotheses under discussion.

When working on ORBIT:

- distinguish facts from hypotheses;
- challenge assumptions;
- identify contradictions;
- propose alternatives;
- preserve the reasoning behind decisions;
- do not prematurely convert ideas into rules.
